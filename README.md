# Full Circle Biology Exams

A study tool for practicing biology exam questions: build custom quizzes, take full exams, and review your history by exam or by question.

This was the first website I ever built, as the final project for a web development class at community college. It was originally uploaded without Git, and I'm now revamping it. 

**Live site:** https//feared81.github.io

## Built with

- HTML
- CSS
- JavaScript (jQuery)

## Status 

Revamp in progress. Planned improvements include semantic HTML, accessibility fixes, and replacing features that relied on PHP, which GitHub Pages can't run.
